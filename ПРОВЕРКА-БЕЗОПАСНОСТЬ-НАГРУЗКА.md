# Проверка 11.11: пути, нагрузка, безопасность

## Пути человека (все проверены автотестами, 218 проверок)

**Гость:** открыл бота → Поиск (город, даты, гости) → карточка (улица и дом видны) → «Забронировать» →
номер и согласие → «Отправить запрос» → ответ хозяина в чат бота и в «Моё» (само обновляется) →
после подтверждения: квартира, телефон хозяина → отзыв после выезда. Отменить, удалить из списка, написать хозяину,
удалить своё сообщение, удалить переписку у себя, пожаловаться.

**Хозяин:** «Сдать» → номер → заявка (имя, город) → модератор одобрил → анкета (фото, тип, город, улица и дом,
квартира, цена, залог, пара слов описания) → «Опубликовать» → бот проверил: чисто — сразу в поиске, иначе к модератору →
запросы гостей (кнопки в чате и в приложении) → календарь, снять на время, удалить объявление.

**Команда:** главный — `/admin <код>` боту (5 попыток в час). Модератор — по одноразовому приглашению `/join ABCD-1234`.
Админка — отдельная страница: «Получить код» → код боту → «Это вы?» → «Да». Выход: кнопка, `/logout_all`, снятие из команды.

## Нагрузка (scripts/load.mjs)

| Что | Результат |
|---|---|
| API на компьютере, 50 одновременно | ~1200 запросов/с, ответ p50 34 мс, p95 69 мс, ошибок 0 |
| Поиск по 3000 объявлений в памяти | 2 мс |
| Запись в файл-базу на 3000 объявлений + 20 000 броней | **155 мс на каждую запись** — всё это время сервер стоит |

Вывод: код быстрый, узкое место — файл-база (переписывается целиком). Для запуска с людьми нужна YDB.
Автообновление в приложении: «я» раз в 30 с, брони и переписки раз в 15 с, открытый чат раз в 4 с, только когда
приложение на экране. Это ~8–10 запросов в минуту на открытое приложение. Бесплатного 1 млн вызовов в месяц
хватит примерно на 1700 часов открытого приложения в месяц. Начнут упираться — сделаем уведомления вместо опроса.

## Безопасность (OWASP API Top 10, проверено по коду и автотестами)

**Найдено и исправлено:**
1. **Высокая.** Модератора назначали по номеру телефона, а номер в приложении можно вписать любой.
   Злоумышленник мог заранее вписать номер будущего модератора и получить админку.
   → Теперь только одноразовый код-приглашение, который человек отправляет боту из своего MAX.
2. **Средняя.** Код главного `/admin <код>` можно было перебирать через бота без ограничений.
   → 5 попыток в час, неверные попытки пишутся в журнал.
3. **Средняя.** Общий лимит на «Получить код» в админке: один человек мог выбрать все попытки и закрыть вход команде.
   → Лимит по адресу (30 в час) + общий запас.
4. **Низкая.** id вида `__proto__` находил служебный объект JavaScript в базе. → Только свои записи.
5. **Средняя (удобство + защита).** Системные окна confirm/alert в MAX не открываются — кнопки «удалить», «отменить»
   молча не работали. → Свои окна.

**Проверено, всё в порядке:** чужие брони, объявления, переписки, сообщения, календарь, фото по id не открыть и не изменить (API1);
подпись MAX проверяется, поддельная не проходит, вебхук без секрета не принимает события (API2); лишние поля в анкете
(статус, хозяин, «проверено») игнорируются (API3); лимиты на бронь, жалобы, чат, фото (API4, API6); админские действия
только команде, ключ админки не годится для броней и сообщений (API5); сервер сам никуда по ссылкам не ходит (API7);
ошибки без подробностей, фото только `<uuid>.jpg` без путей (API8); сообщения бота — простой текст, без разметки,
ссылку в имя или описание не встроить.

**Осталось, сделать при переезде в облако:**
- Номер телефона из MAX («Поделиться номером») приходит с подписью — проверять её на сервере, когда сверим формат с документацией MAX.
  Пока номер можно вписать чужой: гость может указать не свой номер (на права в команде это больше не влияет).
- Лимиты сейчас в памяти одного сервера; в облаке перенести в YDB, иначе у каждой копии свои счётчики.
- В облаке обязательно: `allowBrowser=false`, без `demo`, секрет вебхука. Иначе любой — «главный».
- Демо на Vercel (`arendbot.vercel.app`) по-прежнему пускает любого как главного — там только тестовые данные,
  настоящих людей туда не звать.
- Контакты в чате прячутся по шаблонам; «восемь девять два семь…» словами пройдёт — на это жалобы и модератор.
